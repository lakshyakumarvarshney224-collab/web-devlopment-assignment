Important Laptop Terms

RAM
RAM is temporary memory used by a computer to run programs.
SSD
SSD is a storage device that stores files and programs.
CPU
CPU is the main processor that performs computer operations.
GPU
GPU processes graphics and is useful for gaming and graphics-related work.
Refresh Rate
Refresh rate is the number of times the screen refreshes every second.
Battery Capacity
Battery capacity tells us how much power the laptop battery can store.
